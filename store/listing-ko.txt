QRify는 텍스트나 지금 보는 페이지를 클릭 한 번으로 QR 코드로 만듭니다. 코드는 브라우저 안에서 오프라인으로 그립니다.

코드 만들기
- 텍스트나 URL을 입력하거나, 버튼 하나로 현재 페이지 주소를 가져옵니다
- 페이지에서 선택한 텍스트, 링크, 이미지를 우클릭하고 QRify를 고르면 다시 입력하지 않고 바로 코드가 됩니다
- 한글, 이모지를 비롯한 모든 텍스트를 UTF-8로 인코딩해서, 휴대폰으로 스캔하면 원문 그대로 읽힙니다
- Ctrl+Shift+Q(macOS는 Cmd+Shift+Q)로 팝업을 엽니다

원하는 모양으로
- 코드 색과 배경색, 네 가지 크기 중 하나를 고릅니다
- 스캐너가 코드를 찾는 데 필요한 여백을 항상 함께 그립니다
- PNG로 내려받거나, 시스템 공유 창으로 보냅니다

이어서 쓰기
- 최근 코드 10개를 색과 크기와 함께 최근 기록에 남겨, 클릭 한 번으로 다시 엽니다
- 밝은 테마와 어두운 테마. 따로 고르지 않으면 시스템 설정을 따릅니다
- 브라우저 언어에 맞춰 영어와 한국어로 표시

개인정보
- 네트워크 요청 없음, 분석 도구 없음, 서버 없음
- 최근 코드와 테마만 이 브라우저의 확장 프로그램 저장소에 보관합니다
